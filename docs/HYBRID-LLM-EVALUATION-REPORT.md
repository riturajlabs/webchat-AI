## Test Dataset

- **Dataset**: Default GoldenDataset (6 representative queries)
- **Topics**: pricing, free trial, integrations, support, security, team plans
- **Knowledge base**: 12 seeded chunks across 6 document groups

## Methodology

1. **Vector path**: Each query goes through the standard RAG pipeline with `VectorRetrievalStrategy` (vector-only cosine similarity ranking).
2. **Hybrid path**: Same query goes through the RAG pipeline with `HybridRetrievalStrategy` (vector + keyword RRF fusion).
3. **LLM Judge**: A real Gemini model evaluates both answers on 6 dimensions (correctness, completeness, relevance, hallucination risk, citation quality, overall).
4. **Golden evaluation**: Automated keyword/source/concept coverage scoring.
5. **Latency**: Wall-clock time measured for retrieval, generation, TTFT, and total.

All operations are isolated — no production state mutation.
